# NPC Portrait Gallery

A system-agnostic Foundry VTT module for sharing an NPC portrait gallery with the party. The interface is in Russian.

## Install

In Foundry Setup, open Add-on Modules, choose Install Module, and paste this URL in the Manifest URL field:

https://github.com/Targendorf/npc-portrait-gallery/releases/latest/download/module.json

Enable NPC Portrait Gallery in your world. Open it using the card icon at the bottom of the scene toolbar.

## Use

GMs can publish Actors to the gallery and enter cities, organizations, and ancestries. Players can search, filter, mark favorites, and use personal screen pins. Right-click a card for available actions. Drag a pin onto another to group them, then click the group name to collapse or expand it.
